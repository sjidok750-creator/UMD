# 예제와 출력 미리보기

`*.pmproj.json`은 프로그램의 파일 열기 메뉴에서 불러오는 예제 프로젝트입니다. `guided-demo.pmproj.json`은 그림 기반 형상·철근배근 입력 예제이며, `rectangle.pmproj.json`, `hollow-circle.pmproj.json`, `pier-demo.pmproj.json` 등으로 입력과 계산 흐름을 확인할 수 있습니다.

`reference-*`, `manual-2008`, `additional-*` 프로젝트와 비교 CSV는 공개 예제 검산에 사용한 조건입니다. 각각의 재료·응력블록·계수 모드가 다르므로 한 예제의 기준을 다른 설계에 그대로 적용하지 마세요. 출처와 남은 차이는 저장소 루트의 검증 문서에 기록했습니다.

PNG/JPG는 화면과 보고서 출력 예시이며 EMF는 벡터 그림입니다. 계산으로 생성되는 대용량 곡선 CSV, 상태 JSON, HTML 등은 전체 검증 실행 시 `artifacts/`에 다시 생성됩니다. 포함된 비교 자료는 0.8 배포 시점의 기록입니다.
